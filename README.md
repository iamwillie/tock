# Tock

A lightweight, client-side timesheet for capturing work as you go.

> Capture work as you go. Everything is stored only in this browser.

## Features

* Track time by project/task in 15-minute increments
* Add work types and descriptions
* Weekly totals and daily averages
* Project/task visualizations
* Inline editing
* CSV import and export
* Light and dark themes
* Responsive design
* Local browser storage
* No backend or database required

## Getting Started

Tock is a single-file HTML application with no installation or build process.


## Data & Privacy

Tock stores timesheet data locally using your browser's `localStorage`. Nothing is sent to a server.

Browser data can be cleared, so periodically use **Export CSV** to create a backup. Exported files can be restored using **Import CSV**.

## Technology

Built with HTML, CSS, and vanilla JavaScript. No frameworks, APIs, databases, or external services are required.
